# PatchManager v1.9.0

Prepared: 2026-11-04. Publication and live provider smoke tests are separate gates.

This release fixes crashes, security gaps and false KEV matches found in a full
code audit. JSON/CSV report shapes are unchanged. Some behaviour is stricter;
read **Before you upgrade** first.

## Before you upgrade

- **Elevated runs refuse untrusted files.** If a non-administrator account owns
  or can write Invoke-PatchManager.ps1 or the config file, an elevated run now
  stops with exit code 2. Self-update replaces the main script, so an install in
  a user-writable folder stops patching after it updates. Check the folder ACLs
  (Program Files or ProgramData with default permissions are fine) or fix them
  before allowing self-update to 1.9.0.
- **Commercial profiles refuse user-writable executables.** Commercial and
  CommercialManaged refuse per-user updaters (for example Brave under
  `%LOCALAPPDATA%`), Scoop/py shims and user PATH entries. Personal is unchanged.
- **Stricter configuration.** `Logging.RetentionDays` must be at least 1, and
  `SLA.Enabled` must be a boolean or null. Run `-ValidateConfig` before rollout.
- **New sign-in task shape.** `-InstallStartupTask` now registers a logon task
  for any member of the local Administrators group with no boot trigger.
  Re-run it to replace an existing task.

## Changes

- Crashes fixed: `Ring.Delays` overrides, `ExtraCatalogue` entries without
  optional fields, failed JSON report writes, truncated KEV caches and corrupt
  state files (now preserved as `*.corrupt-<stamp>`).
- KEV/SLA messages log at WARN, so clean runs exit 0 and 3010 still returns.
- KEV matching handles `.NET Framework` and `Visual C++`, maps Chromium entries
  to Chrome, ignores ChromeOS CPEs and AppX sub-products such as
  `Microsoft.Edge.GameAssist`, and runs much faster. NVD lookups retry once.
- WinGet text parsing ignores footers, pin notices and truncated ids; non-English
  output without the WinGet module is reported as a failed discovery.
- Timeouts kill the whole process tree; firmware "no updates" codes, Store
  verification, Chocolatey versions and ARM64 WinGet selection are fixed.
- Overnight windows, dual batteries, console idle time as SYSTEM, SLA clock
  carry-over, popup timing and reboot exit codes are fixed.
- The fleet report takes host identity from the share folder; CSV exports
  neutralise spreadsheet formulas; each host prunes its central share folder.

See [the changelog](../../CHANGELOG.md) for the full list.

## Upgrade

Deploy both scripts from the package to receive the device and fleet fixes.
Self-update replaces only Invoke-PatchManager.ps1. Preserve the installed config,
logs, reports, cache, and state; compare the example config and run ValidateConfig
before rollout. ExpectedSha256 pins the main script, not the release ZIP.
See [the release guide](../RELEASING.md) for verification and rollback.

## Validation boundary

Automated preparation covers static/fixture tests on Windows PowerShell 5.1
and PowerShell 7, runtime validation of the example config, documentation checks,
PSScriptAnalyzer's zero-error policy, browser report tests, and package hash
verification. An elevated dry run passed on one Windows 11 host (PowerShell 5.1,
Personal profile). These checks do not install updates or validate real provider
behavior. Windows 10 pilot smoke tests, a live Pilot run and publication must be
recorded by the release operator before rollout. No live-provider or publication
success is claimed by this document.
