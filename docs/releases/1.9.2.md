# PatchManager v1.9.2

Prepared: 2026-11-04. Publication and live provider smoke tests are separate gates.

This patch release fixes the software inventory, which has contained only
Microsoft Store (AppX) packages since the public beta. Report shapes, exit codes
and configuration are unchanged from 1.9.1.

## Changes

- Classic desktop apps installed through the registry are now inventoried. The
  script runs in PowerShell strict mode, and uninstall keys without a
  `SystemComponent` value made the registry read fail and drop every entry.
- As a result, the KEV, NVD and end-of-life inventory scans now check desktop
  software, and the Chocolatey check skips packages already updated outside
  Chocolatey (for example LibreOffice) instead of failing on a downgrade.

## Upgrade

The first run after upgrading inventories many more products. Expect more NVD
lookups (up to `MaxLookupsPerRun`, 120 by default) and possibly new KEV or NVD
findings for desktop apps that were never checked before. Review them as real
findings.

Self-update replaces Invoke-PatchManager.ps1, which carries the whole fix.
Preserve the installed config, logs, reports, cache, and state. See
[the release guide](../RELEASING.md) for verification and rollback.

## Validation boundary

Automated preparation covers static/fixture tests on Windows PowerShell 5.1
and PowerShell 7, runtime validation of the example config, documentation checks,
PSScriptAnalyzer's zero-error policy, browser report tests, and package hash
verification. The inventory fix was checked on one Windows 11 host under strict
mode (0 registry apps before, 98 after), but a full run with the fix was not
performed. These checks do not install updates or validate real provider
behavior. No live-provider or publication success is claimed by this document.
